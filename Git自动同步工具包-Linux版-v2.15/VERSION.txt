Git 自动同步工具包 v2.15 (Linux 版)
作者: wowsony
仓库: https://github.com/dsduyopg/linux_heima
打包日期: 2026-08-31
兼容: RHEL / CentOS / Fedora / AlmaLinux / Rocky 等使用 systemd 的发行版

本版本由 Windows v2.15 (PowerShell + NSSM) 移植而来：
  NSSM 服务注册       ->  systemd 服务（每仓库一个 git-autosync@<名称>.service）
  FileSystemWatcher   ->  inotifywait 实时监听（3 秒防抖合并连续改动）
  定时拉取常驻服务     ->  systemd timer（git-autosync-fetch.timer）
  .NET SmtpClient     ->  python3 smtplib（邮件通知）
  %USERPROFILE% 配置   ->  /etc/git-autosync（保证 root 运行的 systemd 服务可读）
  %ProgramData% 邮件配置 -> /etc/git-autosync/mail_config.txt

功能:
  1. 本地文件夹自动推送 Gitee / GitHub（实时监听，自动提交推送）
  2. 云端仓库镜像定时拉取（reset --hard + clean，可用 GIT_MIRROR_CLEAN=0 关闭清理）
  3. 服务一键安装 / 修复 / 重建 / 卸载
  4. 新建仓库时可排除目录/文件；已有仓库可移除推送目录（本地文件保留）
  5. 自动检测并清理残留 index.lock，避免同步卡死
  6. [v2.15] 邮件通知：同步成功/失败自动发邮件，可随时开关（默认关闭）

邮件通知（可选，默认关闭）:
  1. 运行 sudo git-autosync mail
  2. 选 [1] 开启并绑定 SMTP
  3. 选邮箱类型（QQ / 163 / Gmail / 自定义），填：发件邮箱 + SMTP 授权码 + 收件人
  4. 选 [3] 发一封测试邮件，收到即配置成功
  5. 想停用：选 [2] 关闭邮件通知

  授权码不是邮箱登录密码：
    QQ 邮箱 : 设置 - 账户 - POP3/SMTP服务 - 生成授权码
    163 邮箱: 设置 - POP3/SMTP/IMAP - 开启 - 生成授权码

  不配置 = 一封都不发，行为与 v2.14 完全一致（零开销、零风险）

快速开始: sudo git-autosync
