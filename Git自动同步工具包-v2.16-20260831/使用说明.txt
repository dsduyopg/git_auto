作者：wowsony · 仓库：https://github.com/dsduyopg/linux_heima · 反馈：GitHub Issues

三步上手
========
1. 双击 环境自检.bat
   -> 自动检查 Git / SSH 密钥 / nssm

2. 双击 新建自动推送仓库.bat 或 新建云端镜像拉取.bat
   -> 按提示输入路径、平台、远端地址
   -> 新建仓库时可填写不推送的目录/文件

3. 可选: 双击 安装定时拉取服务.bat
   -> 每小时自动拉取云端镜像到本地

已有仓库不想推送某个目录/文件
========
双击 移除推送目录.bat
-> 输入仓库路径和要排除的目录/文件即可

日常管理
========
双击 服务管理.bat -> 查看状态 / 启动 / 停止 / 修复 / 卸载

可选: 邮件通知
========
1. 双击 邮件通知配置.bat  ->  [1] 开启并绑定 SMTP（填发件邮箱+授权码+收件人）
2. 服务管理.bat -> [I] 邮件服务管理 -> 输入仓库序号开关该仓库的邮件通知
3. 按 [S] 安装并启动监控服务（会自动发一封测试邮件）
不配置 = 一封都不发。
