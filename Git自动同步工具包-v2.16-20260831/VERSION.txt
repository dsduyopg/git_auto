Git 自动同步工具包 v2.16（通用发布版）
作者: wowsony
仓库: https://github.com/dsduyopg/linux_heima
打包日期: 2026-08-31
兼容: Windows 10 / 11（需安装 Git）

本版本特点:
  - 通用发布版: 不含任何个人路径 / 账号 / 凭证, 任意一台电脑解压即用
  - 功能与 v2.15 完全一致, 另补齐了"邮件服务管理"菜单入口

功能:
  1. 本地文件夹自动推送 Gitee / GitHub
  2. 云端仓库镜像定时拉取
  3. 服务一键安装 / 修复 / 重建 / 卸载
  4. 新建仓库时可排除目录/文件; 已有仓库可移除推送目录
  5. 自动检测并清理残留 index.lock, 避免同步卡死
  6. 邮件通知: 同步成功/失败自动发邮件, 可随时开关
  7. [v2.16 补齐] 邮件服务管理 [I]: 列出本机所有已装同步服务的仓库,
     输入序号即可开关该仓库的邮件通知

邮件通知（可选, 默认关闭）:
  1. 双击  05-邮件通知\配置SMTP.bat  （根目录 邮件通知配置.bat 是同一个入口）
  2. 选 [1] 开启并绑定 SMTP
  3. 选邮箱类型（QQ / 163 / Gmail / 自定义）, 填: 发件邮箱 + SMTP 授权码 + 收件人
  4. 选 [3] 发一封测试邮件, 收到即配置成功
  5. 想停用: 选 [2] 关闭邮件通知

  授权码不是邮箱登录密码：
    QQ 邮箱 : 设置 - 账户 - POP3/SMTP服务 - 生成授权码
    163 邮箱: 设置 - POP3/SMTP/IMAP - 开启 - 生成授权码

  不配置 = 一封都不发（零开销、零风险）

按仓库开关邮件（推荐）:
  管理员运行 服务管理.bat -> [I] 邮件服务管理
  -> 输入仓库序号, 切换该仓库的邮件通知开关
  -> 按 [S] 安装并启动 GitAutoSyncMail 监控服务

快速开始: 双击根目录 环境自检.bat
完整操作手册: docs\操作手册.md
