# Git 自动同步工具包 v2.16（通用发布版）

让**任意文件夹自动同步到 Gitee / GitHub**，或把**云端仓库自动拉取到本地**。
全程不用手动敲 git 命令，双击 `.bat` 就能用，0 基础可上手。

> 作者：wowsony · 仓库：https://github.com/dsduyopg/linux_heima · 使用中有问题请在 GitHub Issues 反馈

---

## 一、这个包解决什么问题

| 你遇到的情况 | 这个包怎么帮你 |
|---|---|
| 写文档/代码忘了手动提交推送 | 文件夹一有改动，**自动提交并推送**到云端 |
| 想在多台电脑间同步一个目录 | 一端推送，另一端**自动拉取**，全程后台 |
| 不想同步某些私密子目录 | 新建时可**排除**，已有仓库可**移除推送** |
| 同步失败了自己不知道 | 可选开启**邮件通知**，成功/失败都会发信 |
| 服务挂了不会修 | 一键**修复 / 彻底重建**，不用碰命令行 |

开机自动运行，重启电脑也会继续同步。

## 二、快速开始（3 步，约 5 分钟）

### 第 1 步：准备（每台电脑只需一次）
1. 安装 Git：<https://git-scm.com/download/win>（一路 Next）
2. 双击根目录 **`环境自检.bat`**，按提示检查并生成 SSH 钥匙
3. 把生成的公钥添加到 Gitee / GitHub 账号（脚本会复制公钥到剪贴板）

> SSH 钥匙是"通行证"，不配好连不上仓库。

### 第 2 步：选一个用法

| 想做什么 | 双击哪个 |
|---|---|
| 本地文件夹 → 自动推到云端 | **`新建自动推送仓库.bat`** |
| 云端仓库 → 拉取到本地 | **`新建云端镜像拉取.bat`** |
| 定时自动拉取云端更新 | **`安装定时拉取服务.bat`**（需管理员） |

### 第 3 步：日常管理
双击 **`服务管理.bat`**（会自动请求管理员权限），所有操作都在这个菜单里。

## 四、邮件通知（可选，默认关闭）

**不配置就一封都不发**，行为和没开过一样，零开销零风险。

### 4.1 配置邮箱（只需一次）
1. 双击 `05-邮件通知\配置SMTP.bat`（根目录 `邮件通知配置.bat` 是同一入口）
2. 选 **[1] 开启并绑定 SMTP**，再选邮箱类型（内置 QQ / 163 / Gmail 预设）
3. 填：发件邮箱 + **SMTP 授权码** + 收件人
4. 选 **[3] 发一封测试邮件**，收到就说明配置成功
5. 想停用：选 **[2] 关闭邮件通知**

> **授权码不是邮箱登录密码**。
> QQ 邮箱：设置 → 账户 → POP3/SMTP服务 → 生成授权码
> 163 邮箱：设置 → POP3/SMTP/IMAP → 开启 → 生成授权码

### 4.2 按仓库开关（推荐，v2.16）
1. 管理员运行 `服务管理.bat` → **[I] 邮件服务管理**
2. 菜单会**自动列出本机所有已装同步服务的仓库**（动态扫描注册表，换电脑通用）
3. **输入仓库前面的序号**，即可切换该仓库的邮件通知开/关
   - `[A]` 全部启用 · `[N]` 全部关闭
4. 按 **[S]** 安装并启动 `GitAutoSyncMail` 监控服务（会自动发一封测试邮件）
   - `[X]` 停止该服务

以后新增了仓库同步服务，重新进 `[I]` 就能看到它，输序号即可加入，不用改任何脚本。

> 同步失败邮件带 30 分钟节流，不会刷屏。

## 六、通用性与隐私说明（重要）

**这是一个干净的通用发布版，可以直接分发给别人使用。**

- ✅ **不含任何个人路径**：脚本全部使用相对路径与系统环境变量（`%ProgramData%`、`%USERPROFILE%` 等），换一台电脑解压即用
- ✅ **不含任何账号 / 密码 / 授权码**：SMTP 授权码由使用者**自己在本机输入**，只保存在使用者自己电脑的 `%ProgramData%\GitAutoSync\mail_config.txt`，**不随本包分发**
- ✅ **不含服务器 IP 或内网地址**
- ✅ **nssm 已内置**（`04-一键部署\nssm_bin\nssm.exe`），无需联网下载

### 关于作者署名
包内保留了原作者署名（作者名与仓库地址），出现在：
`VERSION.txt`、`README.md`、`使用说明.txt`、`docs\0基础入门.md`、`service_manager.ps1`、`LICENSE`。

如果你想改成自己的名字，全局替换作者名与仓库地址即可，不影响任何功能。

## 八、常见问题速查

| 问题 | 解决 |
|---|---|
| 双击 bat 一闪而过 | bat 与同名 ps1 必须**在同一文件夹**，且 ps1 不要改名 |
| 提示找不到 SSH 密钥 | 运行 `生成SSH密钥.bat` |
| 推送报 `Permission denied (publickey)` | 公钥没添加到平台账号 |
| 同步卡在 `index.lock` | 脚本会自动清理残留锁；仍卡住就运行 `修复服务.bat` |
| 服务启动失败 / PAUSED | 运行 `修复服务.bat` |
| 装服务提示权限不足 | 右键 → **以管理员身份运行** |

完整排查见 **`docs\操作手册.md`**。
