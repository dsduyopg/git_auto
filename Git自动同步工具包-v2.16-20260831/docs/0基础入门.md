# Git 自动同步工具包 · 0 基础入门

> 这个工具包能让你的文件夹**自动同步到 Gitee/GitHub**，也能把**云端的仓库自动拉取到本地**。全程不用手动敲 git 命令，双击就能用。

---

## 一、这个包能干什么（两种用法）

| 用法 | 效果 | 用什么 |
|------|------|--------|
| **A. 推送** | 本地文件夹一有改动 → 自动提交并推送到你的 Gitee/GitHub | `01-新建推送仓库` |
| **B. 拉取** | 云端仓库有变化 → 自动克隆/更新到本地指定文件夹 | `02-拉取云盘镜像` |

---

## 二、开始前：先准备 2 样东西（只需一次，约 5 分钟）

### 1. 安装 Git
- 下载：<https://git-scm.com/download/win>
- 一路点"Next"装完即可

### 2. 生成 SSH 密钥（你的"钥匙"）
- 直接双击根目录 **`生成SSH密钥.bat`**，输入名称回车即可，公钥会自动复制到剪贴板。
- （或者手动打开"命令提示符"输入 `ssh-keygen -t ed25519 -f %USERPROFILE%\.ssh\id_ed25519 -N ""`）
- 然后查看公钥：
  ```
  type %USERPROFILE%\.ssh\id_ed25519.pub
  ```
- 把输出的**一整行**复制，添加到你的平台账号：
  - **Gitee**：登录 → 设置 → SSH公钥 → 粘贴保存
  - **GitHub**：Settings → SSH and GPG keys → New SSH key → 粘贴保存

> ⚠️ 这一步是"钥匙"，不配好连不上你的仓库。

## 三、建议先跑一次"环境自检"

双击 **`04-一键部署\开始使用.bat`**，它会自动检查：
- ✅ Git 装了吗
- ✅ SSH 钥匙有吗（没有会帮你生成）
- ✅ nssm 在吗

检查完它会告诉你下一步怎么走。

## 四、用法 A：本地文件夹自动同步到云端

### 前提
- 先在 Gitee/GitHub 网页上**建一个空仓库**（不会的话百度"Gitee 新建仓库"）

### 步骤
1. 双击 **`01-新建推送仓库\新建同步仓库-通用版.bat`**
2. 依次输入：
   - 仓库本地路径（如 `D:\我的项目`）
   - 平台（1=Gitee，2=GitHub）
   - 远端地址（如 `git@gitee.com:你的用户名/仓库名.git`）
3. 工具自动完成：建仓库 → 配置 → 装服务 → 自动同步

### 之后的效果
- 这个文件夹里**增、删、改**任何文件 → 自动提交并推送到云端
- **开机自动运行**，电脑重启也会继续同步

---

## 五、用法 B：把云端仓库拉取到本地

### 步骤
1. 双击 **`02-拉取云盘镜像\新建拉取镜像.bat`**
2. 依次输入：
   - 远端地址（任意 Gitee/GitHub 仓库，如 `git@gitee.com:任何人/仓库.git`）
   - 目标目录（你想放哪就填哪，如 `D:\下载区\某某项目`）
   - 分支（回车默认）
3. **立即克隆**到目标目录，内容马上出现

### 之后的效果
- 想看云端最新，再运行一次这个 bat 就会更新
- 想**定时自动更新**：双击 `02-拉取云盘镜像\安装定时拉取服务.bat`（会自动请求管理员权限），之后每小时自动拉取所有已登记的镜像

> ⚠️ 定时拉取会把镜像目录强制同步成云端最新版（`reset --hard`），并清理目录里的未跟踪文件；镜像目录里自己放的东西会被覆盖/删除。设置环境变量 `GIT_MIRROR_CLEAN=0` 可以关闭"清理未跟踪文件"。

## 五.5、不推送某个目录/文件（用法 B2）

### 新建仓库时
运行 **`01-新建推送仓库\新建同步仓库-通用版.bat`**，输入仓库路径后，再填写要排除的目录/文件即可（多个用逗号分隔）。
- 这些内容会写入仓库的 `.gitignore`
- 实时同步脚本也会忽略这些目录，不再因里面的变化频繁触发同步

### 已有仓库时
1. 双击根目录 **`移除推送目录.bat`**，或在 `服务管理.bat` 中选择 `[H] 删除/排除仓库里的子目录`
2. 输入 Git 仓库路径，再输入要停止推送的目录/文件，例如 `内部资料\私密文件`
3. 工具会：写入 `.gitignore` → 从 Git 索引移除（本地文件保留）→ 更新实时同步脚本
4. 按提示选择是否立即提交并推送；若同步服务正在运行，重启对应服务后新规则生效

> ⚠️ 注意：如果这个目录之前已经推送到 GitHub，普通删除只能让最新版本不再包含它，历史提交里仍可能存在。需要彻底清历史请用 `git filter-repo` 或新建仓库重新上传。

> 也可以直接把仓库里的子目录路径填到第 1 步，例如 `D:\我的项目\内部资料`，脚本会自动向上找到 Git 仓库并停止推送该子目录。

## 六、出问题了怎么办（用法 C）

### 服务坏了 / 不自动同步了
双击 **`03-修复与重建\修复服务.bat`**（自动请求管理员权限）
- 自动扫描所有同步服务，全部修复

### 服务"已标记删除" / 开机不自启
双击 **`03-修复与重建\彻底重建服务.bat`**
- 彻底重建所有服务

> 这两个脚本会自动请求管理员权限，点"是"即可。

## 七、常见问题

| 问题 | 解决 |
|------|------|
| 双击 bat 一闪而过 | 工具是 bat+ps1 两个文件，必须**放同一文件夹**且 ps1 别改名 |
| 提示找不到 SSH 密钥 | 回到"二、2"生成密钥 |
| 推送报 Permission denied (publickey) | 公钥没添加到平台账号，重新检查"二、2 第3步" |
| 同步卡在 `index.lock` | v2.14 会自动清理残留锁；若仍卡住，运行 `03-修复与重建\修复服务.bat` |
| 服务启动失败 / PAUSED | 运行 `03-修复与重建\修复服务.bat` |
| 想删除某个服务的同步 | 管理员：`net stop 服务名` 然后 `nssm remove 服务名 confirm` |
